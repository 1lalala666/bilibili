# Bilibili 视频数据探索性分析看板

基于 Bilibili 分区排行榜 954 条视频数据的交互式可视化看板。

## 项目概述

本看板整合了探索性数据分析（EDA）阶段的核心发现，将数据规律转化为可交互、可探索的可视化界面。

### 数据来源
- Bilibili 分区排行榜 API
- 10 个主题分区，共 954 条视频记录
- 21 个字段（含派生指标）

### 看板功能
- **核心指标卡片**：总视频数、总播放量、平均互动率等关键指标一目了然
- **交互式图表**：基于 Plotly.js，支持悬停查看数值、缩放、筛选
- **多维度分析**：播放量分布、分区对比、相关性热力图、气泡图等
- **数据洞察**：将 EDA 阶段的核心发现以卡片形式呈现

### 技术栈
- 前端：HTML5 + CSS3 + JavaScript（内嵌于单个 HTML 文件）
- 图表库：Plotly.js（CDN 加载）
- 数据处理：Python pandas（离线预处理，数据以 JSON 嵌入 HTML）
